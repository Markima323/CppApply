# ALLCPP 申摊代码生成器

一个不联网、零依赖的本地网页面板，用来生成并复制两类代码，并在当前浏览器中自动保存所填资料：

- 申摊（调用 `orderPosition.do`）
- 已退摊更新为申请（调用 `updatePosition.do`）

## 使用方法

1. 双击打开 `index.html`。
2. 选择“申摊”或“已退摊更新为申请”。
3. 填写活动、账号和联系人资料。
4. 点击“生成并复制代码”。
5. 登录 ALLCPP，打开对应的活动页面，在浏览器开发者工具的 Console 中粘贴并执行。

填写内容和所选模式会自动成为默认值，下次以相同浏览器、相同页面地址打开时会自动恢复。点击“清空保存”可以同时清空表单并删除这些默认资料。

活动主页一栏既可以填写数字 ID，也可以直接粘贴类似下面的完整链接：

```text
https://www.allcpp.cn/allcpp/event/event.do?event=7214
```

## 字段说明

- 两种模式都需要：活动主页链接、任意一个展品链接、UID、姓名、身份证号、联系电话和电子邮箱。
- 展品链接支持 `allcpp.cn/d/1412772.do` 这类格式，程序会自动提取其中的 `1412772` 作为 `doujinshiid`。
- “已退摊更新为申请”还需要社团页面链接，例如 `https://www.allcpp.cn/c/3005850.do`，程序会自动提取 `3005850` 作为 `circleid`。
- 为兼容原来自动保存的数据，展品 ID 和社团 ID 仍然可以直接填写数字。
- `circleid` 不会写入普通申摊代码，因为原申摊接口中没有该字段。
- 其他请求参数沿用原代码的固定值。

## 隐私与操作提示

- 页面不会发起网络请求，也不会上传输入内容；填写资料会使用 `localStorage` 明文保存在当前浏览器本机。
- 共用电脑上使用后，请点击“清空保存”。清除浏览器网站数据也会移除默认资料。
- 直接通过 `file://` 打开时，本地保存范围由浏览器和文件路径决定；移动项目后可能需要重新填写。
- 生成的代码和系统剪贴板都包含身份证号、电话、邮箱等敏感资料，请勿转发。
- 将代码粘贴到已登录的 ALLCPP 页面并执行后，会立即发起真实申请；执行前请核对活动 ID、展品 ID、UID 和社团 ID。
- 如果直接双击打开时浏览器拒绝剪贴板权限，页面会自动选中代码，可按 `Ctrl+C` 手动复制。

## 开发验证

项目没有第三方依赖。安装 Node.js 后可运行：

```powershell
node --test
```

也可以在允许执行 npm 脚本的终端中运行 `npm test`。
