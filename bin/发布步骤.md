# GitHub Release 发布步骤

当前准备发布的版本：`v1.3.3`

目标仓库：<https://github.com/Markima323/CppApply>

准备好的附件应为：`bin/release/ALLCPP自动申摊器-v1.3.3.zip`

## 一、发布前检查

1. 确认 `ALLCPPApply/manifest.json` 与 `bin/package.json` 的版本号都是 `1.3.3`。
2. 在仓库根目录运行测试：

   ```powershell
   node --test bin/test/*.test.js
   ```

3. 打开 `chrome://extensions/`，重新加载 `ALLCPPApply`，手动确认面板能够打开。
4. 检查 ZIP 内容。解压后的第一层应只有：

   ```text
   ALLCPPApply/
   使用教程.docx
   ```

5. 运行 `git status`，确认没有 `.env`、Cookie、Token、身份证号、电话、邮箱、真实表单导出或其他隐私文件。
6. `使用教程.docx` 会按原文件发布。请在上传前自行确认其中的文档属性和截图均适合公开。

## 二、提交并推送代码

先查看改动：

```powershell
git status
git diff
```

确认无误后添加文件。建议明确写出需要提交的路径，避免误收隐私文件：

```powershell
git add .gitignore README.md ALLCPPApply bin/package.json bin/test bin/发布步骤.md 使用教程.docx
git diff --cached
```

再次检查暂存内容，确认安全后提交并推送：

```powershell
git commit -m "release: v1.3.3"
git push origin main
```

如果 GitHub 要求登录，使用 Git Credential Manager、GitHub Desktop 或 GitHub CLI 完成授权。不要把密码或访问令牌写进项目文件或命令脚本。

## 三、在 GitHub 网页创建 Release

1. 打开 <https://github.com/Markima323/CppApply>。
2. 点击仓库页面右侧的 **Releases**。
3. 点击 **Draft a new release**。
4. 点击 **Choose a tag**。
5. 输入 `v1.3.3`，选择创建新标签，并确认目标分支是 `main`。
6. 在 **Release title** 中填写：

   ```text
   ALLCPP自动申摊器 v1.3.3
   ```

7. 在说明框中粘贴下方的“Release 说明模板”。
8. 将 `bin/release/ALLCPP自动申摊器-v1.3.3.zip` 拖入附件区域，等待上传完成。
9. 正式稳定版不要勾选 **This is a pre-release**。
10. 保持或勾选 **Set as the latest release**。
11. 建议先点 **Save draft**，重新检查标签、标题、说明和附件。
12. 确认无误后点击 **Publish release**。

GitHub 会自动附加整个仓库的 Source code ZIP/TAR 文件，这是正常现象。普通用户应下载你手动上传的 `ALLCPP自动申摊器-v1.3.3.zip`。

## 四、Release 说明模板

```markdown
## ALLCPP自动申摊器 v1.3.3

### 功能

- 支持普通申摊和已退摊记录更新为申请。
- 自动识别活动、展品和社团页面链接中的 ID。
- 自动保存填写资料并实时检查输入格式。
- 自动打开 ALLCPP 管理页面执行申请。
- 显示操作类型、活动名称以及成功或失败原因。
- 支持一键前往申摊结果页面。

### 安装

1. 下载附件 `ALLCPP自动申摊器-v1.3.3.zip`。
2. 解压 ZIP。
3. 打开 Chrome 的 `chrome://extensions/`。
4. 开启开发者模式，点击“加载未打包的扩展程序”。
5. 选择解压后的 `ALLCPPApply` 文件夹。

压缩包中附有 `使用教程.docx`。

### 注意

- 需要 Chrome 102 或更高版本。
- 执行前请先登录 ALLCPP 并核对全部资料。
- 点击执行按钮会立即发起真实申请。
- 联系人资料会明文保存在当前浏览器本机；共用电脑使用后请点击“清空保存”。
- 本项目为非官方辅助工具，与 ALLCPP 官方无隶属或合作关系。
```

## 五、发布后验证

1. 打开刚发布的 Release 页面。
2. 下载你上传的 ZIP，不要使用 Source code ZIP 代替。
3. 在新的临时目录完整解压。
4. 确认 ZIP 内存在 `ALLCPPApply/manifest.json` 和 `使用教程.docx`。
5. 在 Chrome 中加载解压后的 `ALLCPPApply`。
6. 确认扩展名称和版本为 `ALLCPP自动申摊器 1.3.3`。
7. 打开面板，确认空表单中没有真实活动、展品或社团 ID。

## 六、以后发布新版本

每次发布时依次执行：修改版本号 → 运行测试 → 生成新版 ZIP → 检查隐私 → 提交并推送 → 创建新标签和 Release → 上传 ZIP → 下载复验。

GitHub 官方说明：<https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository?tool=webui>
